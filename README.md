# ASPIRO — From Learning to Career

**ASPIRO is a personalized career-development platform that bridges the gap between learning and employability by connecting structured learning, practical skill development, and career opportunities in one place.**

## Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend & Database:** Supabase, PostgreSQL
- **Authentication:** Supabase Auth
- **Security:** Row Level Security (RLS)
- **Deployment:** Vercel

## Key Features

- **Personalized Learning Roadmaps:** Career-oriented learning journeys tailored to students' goals.
- **Dynamic Learning Platform:** Lessons, coding exercises, quizzes, assessments, and projects managed through an admin CMS.
- **Skill Tracking:** Monitor learning progress and identify skill gaps.
- **Certificates:** Recognize course completion and learning achievements.
- **Internship Opportunities:** Help students discover relevant internship opportunities.
- **Hackathons & Events:** Keep students informed about hackathons and career-building events.
- **Company & Job Matching:** Connect students with relevant companies and job opportunities.
- **Smart Notifications:** Deliver updates about learning activities, internships, hackathons, and career opportunities.
- **Admin Dashboard:** Manage careers, skills, courses, learning activities, students, and notifications.
- **Analytics & Audit Logs:** Support progress monitoring and administrative accountability.

## Architecture

**Career Goals → Learning Paths → Courses → Phases → Days → Activities**

ASPIRO uses a database-driven architecture powered by Supabase PostgreSQL. Learning content is managed through the administrator dashboard rather than hardcoded into individual pages, enabling flexible content creation and management.

## Security

- Secure authentication through Supabase Auth.
- Database-backed administrator authorization.
- Row Level Security (RLS) to protect application data.
- Protected assessment data and controlled student progress updates.

## Impact

ASPIRO brings learning and career preparation together in a single platform, helping students build practical skills, track their progress, earn certificates, discover opportunities, and prepare for employment.

## Vision

To make career development more accessible, structured, and personalized by transforming the way students learn, practice, and connect with opportunities.

**ASPIRO — Learn with direction. Practice with purpose. Progress toward your career.**
